SDG4 Quality Education — Python Tkinter demo

This small demo shows a local GUI app for user sign up / sign in and a homepage with three sample modules.

Run the app:

python app.py

What I created for you:
- app.py : Tkinter GUI (sign in / sign up / homepage / download)
- data/users.json : initial user store
- data/modules/* : three sample module files

Next steps you can ask for:

- Use SQLite for persistent storage
