# SDG 4 — Quality Education (Python + Tkinter)

A simple desktop GUI demo in Python that demonstrates:
- User sign up and sign in
- A home page showing modules (3 example modules)
- Downloading modules to local disk

## Requirements
- Python 3.8+ (Tkinter included in standard Python installers)

## Run
Open a terminal and run:

```powershell
python -m src.app
```

It will create a `data/accounts.json` file and `modules/` files automatically if they don't exist.

## Example modules included
- Foundations of Quality Education
- Modern Teaching Methods
- Assessment & Learning Outcomes

## Notes
- This is a demo app — accounts are stored in plain JSON for simplicity; do not use this storage mechanism for production.
