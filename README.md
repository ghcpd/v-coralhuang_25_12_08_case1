# SDG 4 Quality Education — Demo App

This small Python/Tkinter demo implements a simple sign-up/sign-in flow and an authenticated "home" screen that lists downloadable learning modules.

Requirements:
- Python 3.8+

Run:
```powershell
python main.py
```

The app stores users in a local `users.db` SQLite file and expects module text files in the `modules/` folder.
